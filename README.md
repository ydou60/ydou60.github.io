# SpeakUp

Application pour apprendre à parler anglais, espagnol, italien, allemand, portugais, swahili, lingala, comorien (shingazidja), arabe et chinois : parcours de 18 unités, histoires, laboratoire des sons, révision espacée et correction de la prononciation.

En ligne : https://ydou60.github.io

Tout est dans `index.html` (aucune installation). La progression est enregistrée dans le navigateur.
